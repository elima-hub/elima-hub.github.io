FUNCIONALIDADES

OP-01

CONSULTAR SALDO

Muestra el saldo actual del usuario autenticado en el sistema.

OP-02

RECARGAR

Permite ingresar fondos a la billetera con validación de monto.

OP-03

RETIRAR

Retiro de fondos con validación de saldo suficiente y límites.

OP-04

TRANSFERIR

Movimiento de fondos entre usuarios registrados en el sistema.

OP-05

PAGAR SERVICIO

Pago de servicios categorizados por tipo con notificación al usuario.

OP-06

VER HISTORIAL

Registro de todas las transacciones realizadas en la sesión.

OP-07

// 05

REFLEXIÓN Y APRENDIZAJES

// HABILIDADES DESARROLLADAS

Fundamentos sólidos de Java: clases, herencia, interfaces y clases abstractas. Implementación de principios SOLID y buenas prácticas de programación. Diseño de arquitectura por capas y separación de responsabilidades. Manejo de persistencia mediante serialización de objetos en archivo .dat.

// QUÉ FUNCIONÓ BIEN

La separación por capas (ui, servicio, modelo, repositorio, excepciones) permitió que el código fuera mantenible y fácil de extender. El sistema de excepciones personalizadas resultó clave para controlar los flujos de error de forma limpia y predecible.

// QUÉ SE PODRÍA MEJORAR

Migrar la persistencia a una base de datos relacional (SQL). Reemplazar la interfaz de terminal por una UI gráfica o web. Implementar notificaciones reales (email, SMS) en lugar de consola. Añadir autenticación segura y cifrado de datos de usuarios.
