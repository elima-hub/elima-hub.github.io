ARQUITECTURA

El proyecto sigue el patrón MVC de Laravel, organizado por módulos de dominio. Cada tipo de ítem de la bóveda cuenta con su propia migración, modelo Eloquent, controlador y vistas, relacionados con el usuario autenticado mediante claves foráneas y relaciones hasMany / belongsTo.

MÓDULO · AUTENTICACIÓN

REFLEXIÓN Y APRENDIZAJES

// HABILIDADES DESARROLLADAS

Diseño de modelos relacionales con relaciones hasMany / belongsTo. Implementación de cifrado a nivel de modelo con el encrypted cast de Laravel. Construcción de un módulo transversal (Folders) que se relaciona con múltiples entidades a la vez. Trabajo colaborativo con control de versiones por rama.

// QUÉ FUNCIONÓ BIEN

La carpeta transversal a los 4 módulos simplificó la organización sin duplicar lógica entre tipos de ítem. Usar onDelete('set null') evitó pérdida de datos al eliminar una carpeta. Dividir el trabajo por módulo de dominio permitió avanzar en paralelo sin conflictos mayores de merge.

// QUÉ SE PODRÍA MEJORAR

Añadir autenticación de dos factores (2FA). Implementar cifrado de extremo a extremo en el cliente, no solo a nivel de modelo. Sumar pruebas automatizadas para los módulos críticos de seguridad. Registrar auditoría de accesos más detallada.
